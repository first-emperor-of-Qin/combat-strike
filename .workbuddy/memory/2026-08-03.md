  - 文案更新：WEAPON_FULL_DESC 主动描述 + WSK 面板写明“幻影与本体同步开火 伤害100%等同本体 且幻影恒定电离能状态”。

## 弧电离子局内建模不显示修复（用户新反馈）
- 用户反馈：「弧电离子」的局内武器建模无法显示，请修复。
- **诊断过程**（puppeteer 本地 + 像素分析）：
  - 首轮 home-screen 测试（R:11/L:0）误导为“相机未入场景图”根因；实为 home 屏渲染器不活跃、3D FPS 视图根本没绘制。
  - **真实复现**用 Case A 流程（`startLevel(1)` 进入关卡后再 `equipFromPanel('1ai')` 中段装备）→ 此前实际就能渲染（之前的双持 QA 也是此流程）。结论：相机入场景由 `startLevel` 负责，正常 in-game 流程已 OK。
  - 但 `createArcionModel` 没有相机入场景的防御性兜底，存在隐患（任何在关卡外/异常状态下调用 `createArcionModel` 都会让挂在相机下的武器组不被遍历）。
- **修复**：`createArcionModel` 末尾（`_tryGltfUpgrade` 之后）增加防御性守卫：
  ```js
  if (camera.parent !== scene) { try { scene.add(camera); } catch(e) {} }
  ```
  保证装备时相机一定在场景图里，武器组（作为相机的子节点）必然被 `renderer.render(scene, camera)` 遍历到。
- **验证**：本地 Case A（先 startLevel 再装备）→ 状态 `{camInScene:true, arcGroupParent:'camera', arcVis:true}`、截图双枪清晰可见（R:2606/L:1534 cyan，明显高于 home 屏 R:11/L:0）/tmp/arcion_caseA_after_equip.png。临时 QA 钩子 `window.__arcionModelQA` 已删除。
