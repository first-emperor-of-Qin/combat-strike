# 2026-08-06 工作日志

## 修复 + 降级：黄金决斗(duel) / 托尔之触(thor)

### BUG 修复：黄金决斗局内未显示技能栏
- 根因：`getCurrentWeaponSkills()`（index.html ~28157）缺少 `slot===2 && equippedSecondary==='duel'` 分支，导致 `updateWeaponSkillsDisplay` 调用它返回 `[]` → 面板 `innerHTML=''` 空白。
- 修复：在该函数 `terminus` 分支之后插入 duel 分支，输出 4 个技能卡：
  - `wsk_rmb_duel` 毁灭射击[右键]（active，cdRef duelDevastateCooldown / activeRef duelDevastateActive / maxCd DUEL_DEVASTATE_CD）
  - `wsk_p_duel_mag` 致命磁能[被动]
  - `wsk_p_duel_reload` 自动装填[被动]
  - `wsk_p_duel_deadeye` 死眼[被动]
- 注意：面板 DOM 由 `buildWeaponSkillsPanel()`（~28420）创建，`updateWeaponSkillsDisplay()` 仅更新状态；切武器时需先调 build 再 update。
- QA 验证（puppeteer，临时钩子 `window.__duelQACheck`）：duel 面板 4 技能、panelHasDuel=true(2324字符)、thor 仍 3 技能、0 控制台/页面错误。验证后已删除临时钩子。

### 降级：duel 与 thor 均由 7级 → 4级
- 改动点（两者相同模式）：`WEAPON_DISPLAY_DATA` 的 `quality:7→4` + `qualityLabel:'7级'→'4级'`；`WEAPON_FULL_DESC` 的 `tagline` 7级→4级、`price:50000→10000`。
- 关键：`getQualityDamageMult()` 现已恒返回 1（品质倍率已移除），故降级**不影响实际伤害数值**，仅改标签/颜色/价格/加成描述。
- `WEAPON_FULL_DESC.bonus` 由 `TIER_BONUS[quality]` 循环（~5753）按 quality 自动生成，降级后加成自动变为 4级档。
- 更新了相关注释中的"7级"为"4级"。
- 用户原话理由："机制与强度严重不达标，故降级为4级武器"（属重新分级，未要求改数值）。
