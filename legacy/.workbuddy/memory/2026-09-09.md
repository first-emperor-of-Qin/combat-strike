## 23:02 — STAGE 选关串台的根因修复

## 23:58 — 修复 3 把新武器的两个 BUG
- **BUG #1 (技能栏空白)**：`getCurrentWeaponSkills()` 是显式 `else if` 链，3 把武器必须各自加 1 个分支（slot+equipped+key+detail+cdRef 等）。漏掉就直接空白技能栏。
- **BUG #2 (裂空脉冲无法造成伤害)**：
  - 裂空脉冲是「无限弹匣」武器但走**默认 shoot()**，而 shoot() 里有 `if(ammoCurrent<=0 && !skillEActive && !_isShadow) return;` 和 `if(!skillEActive && !_isShadow) ammoCurrent--;`
  - 用户可能先用其他武器把 ammoCurrent 打到 0，再切到裂空脉冲 → 进 shoot() 立刻 return → 一发打不出
  - **修复**：两处都加 `&& equippedPrimary !== 'liekong'` 豁免
  - 顺手在 equipFromPanel('1lk') 加 `ammoCurrent = Math.max(ammoCurrent, 150)` + `ammoReserve = Math.max(ammoReserve, 1500)`，避免切换来迟弹药不足
- **经验**：给一把「无限弹匣」武器加默认 shoot() 钩时，**必须同时处理 ammoCurrent 检查**——它不是自动 bypass 的。要么豁免，要么装备时强制填满弹药。
