## BUG 修复：关卡选择空白 + 移动端遮罩无文本

- **关卡选择空白**：根因是某次补丁将 `let currentDifficulty = '1';` 和 `let pendingLevelForDifficulty = null;` 意外合并到同一行，导致 `pendingLevelForDifficulty` 变量未正确定义。`renderDifficultyButtons()` 和 `renderLevelSelectPage()` 都在 initAll 中执行，前者引用该变量抛 ReferenceError → `__fpsGate` 捕获 → initAll 后续代码全部中断 → 关卡选择页永远不渲染。
- **修复**：拆分回两行，恢复变量声明独立性。
- **移动端遮罩无文本**：原 `querySelectorAll('*')` 隐藏了 `#mobile-warning` 的所有子元素（只保留了 div 本身 → 黑屏无文字）。修复为 `document.body.children` 仅隐藏 body 直接子元素，保留 `#mobile-warning` 及其内部完整 DOM。
- **验证**：6段语法全过；无头 QA 关卡卡片 20 个、难度按钮 20 个、0 报错；线上 HTTP 200。
