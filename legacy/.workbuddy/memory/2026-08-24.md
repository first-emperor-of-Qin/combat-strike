## 关键坑
- **TDZ：`const zoneS` 必须在 `initScene()` 调用之前声明**——`initScene → createInitialAmmoPacks → zonePackPoints` 闭包链路会在 initScene 期间就读 zoneS。函数声明会提升，const 不会。修复方法：把 `ZONE_SYSTEM_ENABLED/ZONE_GATE/zoneS/_zoneDirVec` 等 const 块整体前移到 `initAll` 内 `try { initScene(); }` 之前。
- **测试方法 ≠ 真实玩**：headless rAF 节流到 ~1.7fps，引擎 `delta` 又有 `if(delta>0.05) delta=0.05` 钳制——3 秒 waveDelay 在 headless 需要 ~35s 真实时间。**QA 不能靠 setTimeout 等待，必须用确定性钩子（`forceWave` + `makeEnemy(n)`）走真实刷怪链路**。
- **WebGL framebuffer 默认不保留**：`renderer.render()` 后立刻 `canvas.toDataURL()` 才能拿到像素。隔开（异步 await）就变黑。
- **Three.js 相机控制是用 `yaw/pitch` 写 `camera.rotation`**，不是 `camera.lookAt()`——`updatePlayerMovement` 里有 `camera.rotation.y = yaw; camera.rotation.x = pitch;`，每帧重置。所以截图钩子要同步 `yaw`/`pitch` 并早返回该函数。
- **puppeteer 页面截图 vs canvas 截图**：页面截图会带上 minimap 等 DOM 叠层；想看 3D 场景必须 `canvas.toDataURL()` 同步抓主 canvas（按 width*height 挑最大那个）。
